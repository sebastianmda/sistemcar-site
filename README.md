# sistemcar.ro

Site-ul SistemCar Service (tinichigerie, vopsitorie, daune RCA/CASCO), găzduit pe Netlify.

- `index.html` – pagina principală
- `rca.html` – oferta RCA (prin Transilvania Broker de Asigurare)
- `script.js` – meniu, formulare Netlify (cu micșorarea pozelor sub limita de 8 MB), ferestre legale
- `img/` – pozele înainte/după și imaginea pentru distribuire

Formularele (`contact-daune`, `oferta-rca`, `contact-email`) sunt Netlify Forms.
Orice modificare urcată pe ramura `main` se publică automat, după ce repository-ul e legat de site în Netlify.
